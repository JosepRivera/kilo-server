*Estado: diseño — aún no implementado.*

Un ADR (*Architecture Decision Record*) es un documento corto que registra una decisión técnica, la alternativa real que se consideró, y por qué se eligió lo que se eligió. No se escribe un ADR por cada decisión — solo por las que tuvieron un cruce de caminos real, donde otra opción razonable perdió a propósito.

**Decisiones descartadas (Producto)** ([ver esa página](/producto/descartado/)) documenta qué **no** se va a construir. Esta sección documenta **cómo sí** se va a construir lo que sí se construye — con las alternativas que se consideraron para cada pieza y por qué se descartaron.
